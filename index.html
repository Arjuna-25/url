🐍 Extract Date from URL

Python Program using Regular Expressions

📌 Objective

To extract Year, Month, and Day from a URL using Python Regular Expressions.

📚 Concepts Used

  • Python re module
  • Regular Expressions
  • Pattern matching

💻 Python Program

import re

def extract_date_from_url(url):
    # Regex to match YYYY/MM/DD or YYYY-MM-DD patterns
    match = re.search(r'(\\d{4})[/-](\\d{2})[/-](\\d{2})', url)
    if match:
        year, month, day = match.groups()
        return year, month, day
    else:
        return None


# Example usage
url = "https://example.com/news/2025/09/18/article-title"

result = extract_date_from_url(url)

if result:
    print("Year:", result[0])
    print("Month:", result[1])
    print("Day:", result[2])
else:
    print("No date found in URL.")

✅ Output

Year: 2025
Month: 09
Day: 18
